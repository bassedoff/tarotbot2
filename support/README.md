# Система поддержки пользователей

## Запуск

```bash
# Из корневой директории проекта
python -m support.support
```

## Архитектура

Новая система поддержки реализует прямую связь между администраторами и пользователями через бота поддержки без использования Forum Topics.

### Для пользователей:

1. Отправка сообщений через команду `/ask` или кнопку "Спросить"
2. Автоматический поиск ответов в FAQ
3. Создание тикетов при необходимости
4. Получение ответов от администраторов в личные сообщения

### Для администраторов:

1. Получение уведомлений о новых тикетах
2. Ответ пользователям через бота
3. Просмотр истории переписки
4. Закрытие тикетов

## Команды

### Пользовательские команды:
- `/start` - Приветствие и главное меню
- `/faq` - Поиск по базе знаний
- `/ask` - Задать вопрос поддержке
- `/tickets` - Просмотр своих тикетов
- `/hours` - Рабочие часы поддержки

### Админские команды:
- `/admin_panel` - Панель управления тикетами
- `/support_stats` - Статистика поддержки

## Конфигурация

Все настройки задаются в файле `.env` в корне проекта:

```
SUPPORT_BOT_TOKEN=ваш_токен_бота
ADMINS=ID_админов_через_запятую
OPENAI_API_KEY=ключ_OpenAI_(опционально)
SUPPORT_FAQ_PATH=support/faq.yaml
SUPPORT_HOURS=10:00-20:00 MSK
SUPPORT_RATE_LIMIT_USER=3
SUPPORT_AUTOCLOSE_HOURS=72
```

## Файлы

- `support.py` - Основной модуль
- `faq.yaml` - База знаний
- `support_tickets.json` - База данных тикетов
- `support_bot.log` - Логи работы
