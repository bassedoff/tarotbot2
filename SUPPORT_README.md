# Система поддержки пользователей

## Новая архитектура

В новой системе поддержки реализована прямая связь между администраторами и пользователями через бота поддержки без использования Forum Topics.

### Как это работает:

1. **Пользователь отправляет сообщение** боту поддержки через команду `/ask` или кнопку "Спросить"
2. **Бот анализирует сообщение** через FAQ и при необходимости создает тикет
3. **Все тикеты сохраняются** в локальной базе данных (JSON файл)
4. **Администраторы получают уведомления** о новых тикетах
5. **Администраторы могут отвечать пользователям** напрямую через бота

### Команды для администраторов:

- `/admin_panel` - Панель управления с открытыми тикетами
- `/support_stats` - Статистика по обращениям

### Команды для пользователей:

- `/start` - Приветствие и главное меню
- `/faq` - Поиск по базе знаний
- `/ask` - Задать вопрос поддержке
- `/tickets` - Просмотр своих тикетов
- `/hours` - Рабочие часы поддержки

### Как отвечать пользователям:

1. Получите уведомление о новом тикете или откройте `/admin_panel`
2. Нажмите кнопку "Ответить" под нужным тикетом
3. Введите ваш ответ в следующем сообщении
4. Ответ будет доставлен пользователю в личные сообщения

### Как закрывать тикеты:

1. В панели администратора или в карточке тикета нажмите "Закрыть"
2. Пользователю будет отправлен запрос на оценку качества обслуживания
3. Тикет будет помечен как закрытый в базе данных

## Конфигурация

Все настройки задаются через переменные окружения в файле `.env`:

```
SUPPORT_BOT_TOKEN=токен_бота_поддержки
ADMINS=ID_администраторов_через_запятую
OPENAI_API_KEY=ключ_API_OpenAI_(опционально)
SUPPORT_FAQ_PATH=путь_к_FAQ_файлу
SUPPORT_HOURS=рабочие_часы
SUPPORT_RATE_LIMIT_USER=лимит_частоты_сообщений_от_пользователя
SUPPORT_AUTOCLOSE_HOURS=время_автозакрытия_тикетов
```

## Файлы системы

- `support/support.py` - Основной модуль системы поддержки
- `support/faq.yaml` - База знаний
- `support/support_tickets.json` - База данных тикетов
- `support/support_bot.log` - Логи работы бота
